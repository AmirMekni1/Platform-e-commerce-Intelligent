> **KARTAGO 3D** est la première plateforme e-commerce tunisienne combinant un **configurateur 3D interactif temps réel à 60 FPS**, une **animation keynote cinématique (style reveal iPhone)**, une **intelligence artificielle dialectale (Derja & Français)**, un **moteur prédictif Machine Learning / NLP**, un système de **facturation électronique certifiée conforme avec timbre fiscal 1.000 DT**, et une console d'administration **« Big Gestionnaire »** pour le pilotage de la rentabilité et des abonnements VIP.

---

## 🌟 Points Forts & Fonctionnalités Clés

### 1. 🎥 Animation 3D Keynote Reveal (Style Commercial iPhone)
- **Rendu WebGL 60 FPS** propulsé par Three.js (sans vidéo MP4 statique lourde).
- **Parcours en 4 scènes dynamiques** :
  1. *Scan Laser Blueprint Holographique* avec grille technique et faisceau laser.
  2. *Éclaté 3D Déconstruit* exposant les couches internes (tige, semelle amortissante EVA, lacets, œillets).
  3. *Assemblage Magnétique & Vague de Choc Cyan* avec alignement physique des pièces.
  4. *Révélation Studio 360°* avec typographie cinématique Apple Keynote.
- **Portail d'Accès Sécurisé (Connexion Requise)** : L'animation protège l'entrée du site, invitant les utilisateurs à se connecter (Google, Email/Mot de passe ou accès 1-clic démo) avant de découvrir le catalogue complet.
- **Interface Épurée** : Pas de boutons intrusifs polluant la navigation.

### 2. 👟 Studio Configurateur 3D Interactif
- **Rotation 360° fluide** à la souris et au toucher (OrbitControls optimisés).
- **Nuancier Tunisien en direct** : Bleu Sidi Bou Saïd, Blanc Carthage, Ocre Sahara, Vert Palme Tozeur, Noir Médina.
- **Vue Éclatée Anatomique** en direct pour inspecter les matériaux techniques (cuir pleine fleur de Sfax, mesh respirant, semelles en caoutchouc vulcanisé).
- **Changement de caméra instantané** : Vue de profil, vue du dessus, vue semelle et vue perspective 3D.
- **Mode Fil de Fer (Wireframe CAD)** et éclairages studio haute fidélité avec ombres douces.

### 3. 🇹🇳 Conseiller Mode IA Tunisien « Sami » (Derja & Français)
- Propulsé par l'API **Google Gemini 3.8**.
- Comprend le dialecte tunisien (Derja en alphabet latin ou arabe) et le français.
- Conseils personnalisés sur le **taillage et correspondances des pointures tunisiennes (EU 38 à 46)**.
- Recommandations de tenues vestimentaires (streetwear chic, chemises en lin, hoodies 460 GSM).
- Synthèse vocale intégrée (**Web Audio API**) pour écouter les réponses audio.

### 4. 🧠 Moteur Prédictif Machine Learning & NLP
- **Analyse du profil client** : Historique d'achats, panier actif, morphologie et préférences.
- **Prédiction de la pointure idéale** avec indice de confiance algorithmique (ex: 94% de match pointure 42).
- **Recommandation de packs complémentaires (Duo Pack)** avec application automatique de réductions intelligentes (-10%).
- **Analyse NLP en temps réel** : Entrez une phrase en langage naturel (ex: *"Je cherche des baskets confortables pour marcher à Tunis et aller au bureau"*) et le modèle extrait l'intention pour configurer le produit adéquat.

### 5. 🧾 Facturation Électronique Conforme à la Législation Tunisienne
- **Émission automatique et instantanée** à chaque passage de commande.
- Mentions légales complètes :
  - **Matricule Fiscal** de l'entreprise : `1849204/B/A/M/000`
  - **Registre de Commerce** : `B0194822026`
  - **Droit de Timbre Fiscal obligatoire** : `1.000 DT` calculé automatiquement.
  - **TVA légale** : `19%` ventilée entre Brut Hors Taxe (H.T) et Net à Payer (T.T.C).
  - **QR Code de vérification fiscale** et hash cryptographique d'authenticité.
- **Envoi électronique automatique par email** du récapitulatif officiel dès confirmation.
- **Téléchargement & Impression PDF** directe via fenêtre d'impression stylisée.

### 6. 👑 Console d'Administration « Big Gestionnaire »
- **Session Administrateur sécurisée** pour les gestionnaires de la plateforme.
- **Section Produits Rentables ("Most Pay")** :
  - Classement des best-sellers par chiffre d'affaires cumulé et marge nette.
  - Suivi des taux de conversion 3D et du volume d'unités écoulées.
- **Section Produits Sous-performants ("Not Good")** :
  - Détection automatique des articles à fort taux de retours ou à rotation lente.
  - Diagnostic IA des causes (ex: taillage trop serré sur les modèles running).
  - Actions correctives en 1-clic : remise déstockage flash, ajustement du guide de pointures.
- **Gestion des Abonnements Club VIP** :
  - Souscription manuelle ou automatique d'utilisateurs au statut VIP (-15% permanent et livraison offerte).
  - Historique de la valeur vie client (LTV) et total dépensé en Dinars Tunisiens (DT).
- **Suivi des Commandes & Colis Aramex** :
  - Numéros de tracking automatiques sur les 24 gouvernorats tunisiens.
  - Réimpression de n'importe quelle facture électronique en un clic.

### 7. 🤍 Design Système Blanc Épuré (Luxury White Theme)
- Esthétique moderne et luxueuse inspirée d'Apple et des grandes maisons de mode.
- Fonds blancs purs (`bg-white`), nuances ardoise légères (`bg-slate-50`), bordures fines (`border-slate-200`) et typographie sombre à fort contraste.
- Composants soignés : cartes produits à coins arrondis (`rounded-3xl`), tiroir de panier fluide, modals élégantes.

## 🏗️ Architecture & Technologies

| Couche | Technologie | Rôle |
|---|---|---|
| **Frontend UI** | React 19 + TypeScript + Vite | Interface monopage (SPA) réactive et ultra-rapide |
| **Rendu 3D** | Three.js (WebGL) | Moteur 3D temps réel, shaders, géométries procédurales et éclairages studio |
| **Styles & Design** | Tailwind CSS v4 | Architecture CSS sans fichier externe, responsive mobile & desktop |
| **Backend API** | Express.js + tsx | Proxy API pour les commandes, la facturation et l'envoi d'emails |
| **Base de Données** | Firebase Firestore | Stockage persistant des commandes, profils utilisateurs, avis et abonnements |
| **Authentification** | Firebase Auth | Connexion sécurisée Google OAuth, Email/Mot de passe et démo 1-clic |
| **Intelligence Artificielle** | Google Gemini 3.8 (@google/genai) | Assistant dialectal tunisien Sami, NLP et analyse prédictive |
| **Transporteur & Logistique** | Intégration Aramex Tunisie | Numéros de suivi colis pour les 24 gouvernorats |

## 🚀 Installation & Lancement en Local

### Prérequis
- Node.js (version 20 ou supérieure recommandée)
- npm ou yarn

### 1. Cloner le dépôt
```bash
git clone https://github.com/votre-compte/kartago-3d-ecommerce.git
cd kartago-3d-ecommerce
```

### 2. Installer les dépendances
```bash
npm install
```

### 3. Configurer les variables d'environnement
Créez un fichier `.env` basé sur `.env.example` :
```env
# Clé API Google Gemini pour l'assistant Sami et les analyses ML
GEMINI_API_KEY="votre_cle_api_gemini"

# URL de l'application
APP_URL="http://localhost:3000"
```

### 4. Lancer le serveur de développement
```bash
npm run dev
```
L'application est disponible sur : `http://localhost:3000`

### 5. Compiler pour la production
```bash
npm run build
npm start
```

## 🇹🇳 Conformité Réglementaire Tunisienne

1. **Devise Nationale** : Tous les montants sont libellés en **Dinars Tunisiens (DT / TND)** avec affichage à 3 décimales (`0.000 DT`), conformément aux usages bancaires de la Banque Centrale de Tunisie (BCT).
2. **Timbre Fiscal** : Prélèvement réglementaire de **1.000 DT** appliqué sur chaque facture électronique émise.
3. **Taux de TVA** : Application de la taxe sur la valeur ajoutée légale de **19%**.
4. **Logistique Nationale** : Intégration des 24 gouvernorats tunisiens (Tunis, Ariana, Sousse, Sfax, Nabeul, Bizerte, Djerba/Médenine, etc.) pour une livraison sous 24 à 48 heures ouvrables.
